## 2. Methodology & Preservation Notice

Every discrepancy recorded above was investigated against primary source artifacts (Jupyter cell outputs, execution logs, JSON configuration files, and Codabench submission archives). No historical records were altered or overwritten. In all instances where local development scores diverged from official Codabench results, the cause was verified as a difference in evaluation splits, postprocessing configurations, or competition server scoring formulas.
